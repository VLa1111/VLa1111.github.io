THE PROBLEM

并行化不是只把计算分给更多卡。

BAGEL 的扩散阶段既有 Transformer token 路径，也有 VAE token 与多阶段 KV cache 的传递。单纯切分 attention 并不能让各 rank 获得正确且完整的上下文；系统必须同时定义数据如何到达、如何广播、如何复原。

3并行策略
Ulysses / Ring / Hybrid
2跨阶段数据链
KV cache + VAE token
1兼容目标
保持 hook-based acceleration

SYSTEM MOVE

把“谁持有数据”变成一个明确的协议。

01

切分序列

Transformer 支持 Ulysses、Ring 以及两者混合的 sequence parallel 配置。

02

传播 KV cache

rank 0 通过 SharedMemory connector 接收 KV cache，再使用 broadcast_object_list 分发给 SP ranks。

03

切分 VAE token

将 VAE token 按 SP ranks 分配，并以一个窄接口避免大范围修改 diffusion model runner。

INTERACTIVE EXPLORER
